# Budarina Flower Shop

The Budarina 3D flower-card website, built with React, Vite and Three.js.

## Flower model files

The 3D models are stored outside Git history in a GitHub Release. For the first deployment:

1. Create a release with the tag `flower-models-v1`.
2. Upload both archive parts from the files supplied by Replit Agent, keeping their exact filenames.
3. Publish the release.

Publishing that release starts the GitHub Pages build. The workflow joins the parts, checks and unpacks all models, builds the site, and deploys it to Pages.

The website is configured for `https://marinabudarina.github.io/budarina-flower-shop/`.
